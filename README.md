
 # RaceDay Management System

## Project Description
RaceDay is a centralized event management platform designed to streamline event organization, race category management, route mapping, participant enrolments, and official result publishing. Built with a T-SQL database architecture and an ASP.NET Core REST API design, the system provides a structured workflow for both race hosts and athletic competitors.

## System Roles
* **Organiser:** Creates and manages events, configures event categories and routes, uploads media, reviews participant enrolments, and publishes official race timings/results.
* **Participant:* Manages personal profile details, searches upcoming races, registers for specific event categories, and views individual performance metrics and overall standings.
